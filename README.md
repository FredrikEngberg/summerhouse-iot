## Project Overview

**Summer House IoT** is a long-term embedded systems and IoT portfolio project where an existing summer house is gradually upgraded with local monitoring, automation and data-driven control.

The project is developed alongside my studies in **Embedded Systems & IoT at Nackademin** and applies software development, sensors, communication protocols, automation and system integration to a real environment.

The main principles are:

- Local-first operation
- Modular system design
- Reuse of existing hardware
- Reliable monitoring and notifications
- Historical data collection
- Secure remote access
- Incremental development and testing

---

## 🔥 Current Focus

The first development phase focuses on the property's heating system and the local IoT platform.

Current areas include:

- Room-level temperature monitoring
- Smart radiator control
- Energy monitoring
- Heating system measurements
- Historical data
- Sensor health and battery monitoring
- Home Assistant integration
- Secure remote monitoring

The first goal is to collect reliable real-world data and understand system behaviour before introducing more advanced optimisation.

---

## 📡 Planned Expansion

The platform is designed to grow over time with additional IoT subsystems.

Planned development includes:

- Wireless property monitoring
- Utility level monitoring
- Door and window monitoring
- Long-range outdoor sensors
- Local and mobile alerts
- Embedded IoT nodes
- Automated maintenance functions
- Data-driven optimisation

Each subsystem is developed and verified separately before being integrated into the complete platform.

## 🧪 Engineering Approach

The project follows a structured development process:

```text
Requirements
    ↓
Planning
    ↓
Architecture
    ↓
Component selection
    ↓
Prototype & bench testing
    ↓
Installation
    ↓
Verification
    ↓
Data collection
    ↓
Analysis
    ↓
Documentation
```

Existing equipment is reused where practical, and modifications are designed to be reversible whenever possible.
