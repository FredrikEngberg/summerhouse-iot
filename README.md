# 🏡 Summer House IoT

A long-term **Embedded Systems & IoT portfolio project** where an existing summer house is gradually upgraded with local monitoring, automation and data-driven control.

The project is developed alongside my studies in **Embedded Systems & IoT at Nackademin** and is used to apply software, embedded development, sensors, communication protocols and system integration to a real property.

---

## 🎯 Project Vision

The goal is to build a modular IoT platform that can:

- Monitor important systems in the property
- Improve heating control and energy visibility
- Collect environmental and system data
- Provide remote monitoring
- Generate useful alerts
- Integrate existing and new hardware
- Continue operating locally when possible
- Provide historical data for analysis and optimisation

A major focus is also placed on **reusing existing hardware instead of replacing functioning equipment**.

---

## 🔥 Current Focus

The first development phase focuses on the heating system.

The platform will provide:

- Room-level temperature monitoring
- Smart radiator control
- Heating system temperature measurements
- Energy monitoring
- Historical data
- Remote monitoring
- Home/Away/Winter operating modes
- Sensor health and battery monitoring

The aim is to better understand how the heating system behaves before introducing more advanced optimisation.

---

## 🖥️ Local IoT Platform

The system is being designed around a dedicated local server running:

- Home Assistant
- Local integrations
- Historical sensor data
- Automation
- Dashboards
- Remote access through a secure connection

The architecture is designed so that critical property functions do not depend entirely on cloud services.

---

## 📡 Future Monitoring

The platform is modular and will later be expanded with additional property monitoring.

Planned areas include:

- Utility level monitoring
- Wireless outdoor sensors
- Property status monitoring
- Door and window monitoring
- Local and mobile alerts
- Long-term environmental data
- Additional embedded IoT nodes

---

## 🧠 Data & Analysis

As the amount of collected data increases, the project will also investigate ways of identifying:

- Heating trends
- Energy usage patterns
- Abnormal sensor behaviour
- Changes over time
- Opportunities for optimisation

AI-based analysis may later be used as **decision support**, while deterministic control and safety functions remain separate.

```text

    ↓

    ↓
Architecture
    ↓
Component selection
    ↓
Prototype / bench testing
    ↓
Installation
    ↓
Verification
    ↓

    ↓
```

Each subsystem is developed and tested separately before becoming part of the complete installation.
